Live data sourceESPN site feeds
Where Arena gets its data: Arena tries free sports-data providers when a team, driver, or constructor page is opened. MLB uses MLB Stats API, Formula 1 uses Jolpica-F1, and other sports use TheSportsDB's free API where coverage is available. These feeds are used by ESPN's own web pages, but they are not a guaranteed public developer API, so Arena includes error handling and fallback links in case a feed changes or is unavailable.
